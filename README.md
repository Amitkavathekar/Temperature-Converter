# 🌡️ Temperature Converter

A simple and fast **Temperature Converter Web Application** that allows users to convert temperatures between **Celsius and Fahrenheit instantly**.

This project demonstrates **JavaScript DOM manipulation and real-time calculation** with a clean and responsive user interface.

🔗 **Live Website**  
https://oibsip-taskno-3-temperature-convert.vercel.app/

## 🚀 Getting Started

### Prerequisites

- Web Browser (Chrome / Edge / Firefox)
- Git (optional)

---

### Installation

Clone the repository

```bash
git clone https://github.com/Amitkavathekar/Temperature-Converter.git
cd Temperature-Converter
```

Open the project

```
Open index.html in your browser
```

## 📌 How It Works

1. Enter a temperature value.
2. Select the conversion type.
3. Click the **Convert** button.
4. The converted temperature will be displayed instantly.
